# YORQ

A custom embedded storage engine built from scratch in modern C++.

YORQ is an ongoing project focused on understanding and implementing the fundamentals of database systems, from low-level data storage to efficient data retrieval.

## Goals

- Build a storage engine from the ground up.
- Understand disk I/O and data persistence.
- Implement indexing and efficient data retrieval.
- Explore database internals through hands-on development.

## Tech Stack

- **Language:** C++
- **Build System:** CMake
- **Version Control:** Git
